# AI Interior Studio (local-first)

Phase 1-3 slice: projects, rooms/doors/windows with validated dimensions, deterministic 3D shell, first-person walkthrough,
file/asset management with trash, a replaceable AI-provider layer (Ollama vision, OpenCV, PaddleOCR), and an AI task center.

**Setup:** `./scripts/setup.sh` then `./scripts/dev.sh` -> open http://127.0.0.1:3000
**Tests:** `./scripts/test.sh`
**Model benchmarks:** see `docs/AI-MODEL-BENCHMARKS.md` and run `scripts/benchmark_models.py`.
**Status:** see `docs/14-IMPLEMENTATION-PROGRESS.md` for exactly what is and is not implemented.
